API Gateway Documentation

Base URL: http://localhost/APIGateway/api/

All requests must include the header:

X-API-Key: your_api_key_here

GET /users

Returns a list of users.

Sample Request:

GET /api/users

Headers:

X-API-Key: key123

Sample Success Response (200 OK):

{
  "users": [
    {"id": 1, "name": "Alice"},
    {"id": 2, "name": "Bob"}
  ]
}

GET /products

Returns a list of products.

Sample Request:

GET /api/products

Headers:

X-API-Key: key123

Sample Success Response (200 OK):

{
  "products": [
    {"id": 101, "name": "Laptop"},
    {"id": 102, "name": "Keyboard"}
  ]
}

Error Responses

  • 401 Unauthorized – Missing or invalid API key
  • 429 Too Many Requests – Rate limit (10 requests per 60s) exceeded
  • 404 Not Found – Invalid endpoint
